# Classic engines

Built with Emscripten 7.0.0 (777e6e5db7b4990bcaeb1b9998ed642cc84e6629) and the compatibility layer in
`engines/` of this repository (`.github/workflows/classic-wasm.yml` is how):

- `pela.*`: Pela by Petr Lastovicka, licensed under the GNU General Public License, from
  [Piskvork](https://github.com/plastovicka/Piskvork) at commit
  [`2c3296514a3735cad83eed8a3134f51324f962ca`](https://github.com/plastovicka/Piskvork/tree/2c3296514a3735cad83eed8a3134f51324f962ca) (`source/pbrain`).
- `slowrenju.*`: SlowRenju by Tianyi Hao, licensed under the GNU General Public License v3.0,
  from [SlowRenju](https://github.com/wind23/SlowRenju) at commit
  [`41007cf70762b62df77223da25c9605d0a853602`](https://github.com/wind23/SlowRenju/tree/41007cf70762b62df77223da25c9605d0a853602), adapted by
  `engines/slowrenju/patch.py`.
